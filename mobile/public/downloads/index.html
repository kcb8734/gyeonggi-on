Play Console에 올릴 AAB

업로드 키가 Play에 등록되어 있습니다. 아래 AAB만 올리면 됩니다. 재설정 요청은 하지 마세요.

파일 onandon_plus_1.0.6_vc7.aab
앱 온앤온+ · 패키지 kr.gyeonggion.app
versionName 1.0.6 · versionCode 7
서명 SHA-1 30:70:7C:14:A2:AA:1B:AD:06:5C:E7:CC:79:AC:02:BB:9B:D8:2C:42

AAB 다운로드 업로드 순서 저장

1. 파일 받기

  1. 위 AAB 다운로드를 눌러 onandon_plus_1.0.6_vc7.aab를 저장합니다. 약 31MB입니다.
  2. 확장자가 .aab인지 확인합니다. 압축을 풀지 마세요.
  3. .jks, PEM, 비밀번호는 올리지 않습니다.

2. Play Console 업로드 (내부 테스트 먼저)

  1. Play Console에 로그인합니다.
  2. 앱 온앤온+ (kr.gyeonggion.app)을 엽니다.
  3. 왼쪽: 테스트 및 출시 → 테스트 → 내부 테스트
  4. 출시 탭에서 새 버전 만들기
  5. App Bundle 업로드에 onandon_plus_1.0.6_vc7.aab만 선택합니다.
  6. Play가 서명 SHA-1을 30:70:7C:…:2C:42로 표시하면 정상입니다.
  7. 출시 이름에 1.0.6 (7)을 넣고, 출시 노트는 아래 문구를 붙여 넣습니다.
  8. 다음 → 저장 및 출시 → 내부 테스트 트랙으로 출시 저장

3. 내부 테스트가 끝난 뒤 스토어 출시

  1. 같은 앱에서 테스트 및 출시 → 프로덕션
  2. 새 버전 만들기
  3. 방금 올린 App Bundle을 라이브러리에서 고르거나, 같은 AAB를 다시 올립니다.
  4. 국가·출시 비율을 확인한 뒤 저장 및 출시 → 프로덕션 트랙으로 출시 저장

프로덕션은 심사 후 스토어에 반영됩니다. 내부 테스트는 보통 몇 분이면 테스터에게 보입니다.

올리면 안 되는 것

APK, .jks, 비밀번호, PEM은 버전 업로드에 쓰지 마세요. 서명 오류가 나면 키를 새로 만들지 말고 이 AAB인지 확인하세요. versionCode 7이 이미 사용됨으로 나오면 알려 주세요.
